## 妙电液态玻璃重设计（v1.7.0）

### 设计语言：「分层玻璃 + 克制着色」

苹果美学核心是**用材质做层级，不用边框和色块**。现状是 `quaternarySystemFill` 灰底卡片 + 发丝描边（PopoverComponents.swift L107-114），改成：

| 元素 | 现状 | 新设计 |
|---|---|---|
| 卡片 `PopoverCard` | 灰底 + 1px 描边，圆角 10 | `.glassEffect(.regular, in: .rect(cornerRadius: 16))`，去掉手动描边（玻璃自带边缘高光），内边距 10/7→12/9 |
| 卡片列 | 独立 VStack | 包进 `GlassEffectContainer(spacing: 10)`——相邻玻璃卡边缘会互相「融合流动」，这是液态玻璃的招牌效果 |
| 头部 | 裸排（无容器） | 整块包进大圆角(20)玻璃卡；圆环仪表下垫玻璃圆底；状态徽章 `Capsule().fill(color.opacity(0.13))` → **着色玻璃胶囊**（`.tint()` 玻璃，深浅色自动适配） |
| 控制行 | 悬停灰底 | 行结构**不动**，悬停态换 `.glassEffect(.regular.interactive(), in: .rect(cornerRadius: 10))`——按压有镜面高光反馈 |
| 图表 | Canvas 自绘 | 全部保留（是内容不是容器），只微调渐变/网格线透明度保证在透底上可读 |
| 曲线窗口 | windowBackgroundColor | 玻璃容器 + `.buttonStyle(.glass)` |
| 设置窗口 | grouped Form | 不动——macOS 26 系统自动给它新观感 |
| 分享卡片 | AppKit 离屏绘制 | 本轮不动（与面板解耦） |

**硬约束**：面板骨架（VStack/HStack/frame 292/584/分列算法/CascadeIn）一律不动——ScrollView 事故的教训是特殊宿主里布局骨架不能碰，这次只换材质层。

### 风险与退路

- **glassEffect 在 MenuBarExtra 宿主里行为未知**（正是 ScrollView 事故的模式）：预览 harness 先排掉 90% 问题；若真实面板里嵌套玻璃异常，退路是卡片降级 `.regularMaterial` 圆角底（仍透、观感接近），按钮/徽章保留玻璃。
- **性能**：玻璃是 GPU 合成，且只在面板打开时存在，符合能量悖论约束；GlassEffectContainer 的 spacing 保守取 10。
- API 精确签名（`Glass.tint`/`GlassEffectContainer(spacing:)`/`.buttonStyle(.glass)`）以 SDK 26.5 编译为准，第 2 步先编译验证。
